# Standalone composition boundaries

The component assembly builds independently of board packages. The following production source suppliers are still required before the composed standalone command can preserve the complete existing behavior. The command now constructs real components and uses the original authenticated serving lifecycle; a successful build does not close the boundaries below.

| Boundary | Actual source requirement | Current limit |
| --- | --- | --- |
| Record codec | `NewLegacyRecordCodec`: original record image and provider subrecord conversion | Original images and unknown fields are preserved. Active native accounting remains refused until complete accounting snapshots, real provider restoration and admitted commit support are supplied. Archival accounting decode/encode alone does not admit runtime restoration. |
| Configuration | `sessionmanager.HostConfig.Snapshot` | `hostdefaults.FileConfig` supplies explicit file-backed timeout/provider defaults and context policy. `Load` validates the original nine optional retention knobs and retains raw bytes; the standalone now binds the actual parsed snapshot and runtime defaults. `ConfiguredContextRetentionSweep` resolves the whole policy before its real service call; existing explicit HTTP requests are not rewritten or merged. Public `FileConfig.Snapshot` still refuses an unbound policy. The command discovers its host config path; real launch-default consumption remains required at the legacy launch-conversion boundary. |
| Notices | `NewSessionNoticeStore` and the host delivery pump | Original structured payloads are delivered as complete bursts; failed delivery retains receipts. `OpenStandalone` binds the actual store to the host. Native delivery still requires its real provider. |
| Control routes | `NewProtocol8Handler(host, server.Status, supplemental)` inside `NewControlServer` | Physical session routes and actual goal/context handlers are composed under `ControlServer`. Captured owner rendering is bound. Actual takeover/doctor and catalog/quarantine status are composed. The original full Attach handler now uses typed conversion, source verification and a captured expected lease under the real outer authentication. A genuine production raising-side source remains absent; explicit owner-run and Codex budget consumers still refuse. The legacy goal descriptor is conditional on its actual retained-source proof; no unknown launch fields become guessed payloads. |
| Goals | `sessiongoal.Service`, `BindingFactory` and actual launcher/operator authority | Durable assignment/working journals and holder-bound delivery exist. New references use the original native codec's accepted goal-ID shape before rendering/store/delivery. Historical experimental references refuse without journal rewriting. Runtime budget bindings and scoped physical HTTP operations are composed. The concrete full legacy validator/proof is installed over the optional retained-source port. Genuine raising-side verified-caller authority and authenticated complete raw/accepted-revision provenance remain required. Without that source the default descriptor stays absent and effects refuse. Native completion text is not acceptance. |
| Native budget persistence | Actual accounting snapshot, renderer and current-lease record commit | Exported archival accounting fields and `NewLegacyMuseAccountingRecords` read/CAS now exist. The adapter verifies the current lease, exact base and accounting-only change through normal codec admission and the sole record writer. Active goal/baseline/ledger state still refuses before write until complete native renderer/restoration support exists; arbitrary raw-image writes would break normal host recovery. |
| Managed owner runs | Captured-lease provider renderers and per-write admission | Holding an input fence across an entire run blocks stop generation; an unguarded provider call bypasses the replaced-controller refusal. `sessionrun` is now composed with the same budget factory and bound host before recovery/attach/serve. Its real two-stage accounting restorer is discovered by the core outside map/epoch locks; this does not itself admit guarded active state. Full active Muse restore and pending Codex goal-plus-prompt integration remain required; current guards remain enabled. |
| Contexts and materialization | `sessioncontext.Service` plus real `ContextAuthority`, current references, provider materializers and builder lifecycle | Catalog, recovery and retention exist, with raw quarantined identities retaining artifacts and leases. Missing current observations remain holds. `NewMaterializationHostCodec` delegates actual legacy conversion; it does not grant authority or unsupported native restoration. The original gateway/trace/finalization runtime and real shim entry are composed, with the same runtime bound to Service. The same runtime is now bound to the core lifetime port: Host.Close finalizes gateways before observation retirement, and standalone serving/drain retains its exact failure before closing the budget factory. Actual core Start-before-provider/Bind-after-provider remains missing, as do genuine native builder observation and the canonical signed record issuer. Host attach materialization wiring is still required. |
| Context fork validation | `ContextForkValidationSource`, actual policy/evidence and coverage-derived boundary | Common DTOs and the port exist. The context service still refuses fork before provider effects until the actual validation decision/banner supplier is integrated. A security permit is not validation evidence. |
| Identity | Existing raising-side SessionStart binding | No replacement binding service is supplied by this module. |

A typed composition that only accepts these interfaces is not a production daemon. A board callback, a copied board implementation, a lossy replacement codec or an all-unsupported handler cannot satisfy these boundaries. The default entry point exposes the real component composition while missing suppliers refuse; it is not complete existing-behavior delivery. The existing authenticated serving lifecycle and shutdown signal watch remain available for that composition.
