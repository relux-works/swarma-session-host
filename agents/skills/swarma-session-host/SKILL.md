# Swarma Session Host

Use this repository's foreground host/runner prototype. The Host owns input intent, receipts and controller epochs; the runner owns one child and its stdio. Current adapters are JSON/line fixtures and Codex 0.164.0; Claude/Muse examples are interface fixtures only. [C01](references/evidence.md#c01)

Start with the route relevant to the request:

- [Commands and verification](references/usage.md): build prerequisites, synthetic run, control envelopes, conditional Codex flags and focused test selection.
- [Trust and refusal boundaries](references/boundaries.md): interpret receipts, uncertainty, stop scope, notification custody and unsupported operations before attempting recovery.
- [Internal extension seams](references/extensions.md): implement and wire a compiled adapter or synthetic admission callback; distinguish those seams from private notification preparation.

G07 and grant consumption are unavailable here. Live runtime and root custody are unavailable for this workflow. Do not claim readiness, admission or production runtime from this skill, a valid binding, an ownership snapshot or a source fixture. Goal controls are reserved and refuse; real hosted integration remains unimplemented. [C00](references/evidence.md#c00)

Preserve queued/unknown intent and the original execution, runner and state on replacement. Query the current epoch; do not resend uncertain input, delete a pending marker or clear a security stop to obtain progress. Same-UID sockets authenticate an OS user and do not isolate agents sharing that account. [C07](references/evidence.md#c07) [C09](references/evidence.md#c09) [C10](references/evidence.md#c10)
